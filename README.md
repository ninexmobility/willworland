# Will Worland — Personal Site

Personal site, resume, and writing for Will Worland. Built with Astro + MDX, styled with Tailwind v4, deployed to Cloudflare Pages.

## Tech Stack

- **Astro 5** (static site, content collections, MDX)
- **Tailwind CSS v4** (utility-first, CSS-first config in [src/styles/global.css](src/styles/global.css))
- **Puppeteer** (build-time PDF generation for the resume)
- **Giscus** (blog comments via GitHub Discussions)
- **Cloudflare Pages** for hosting

## Getting Started

```bash
npm install
npm run resume:chrome   # one-time: download Chromium for PDF generation
npm run dev             # start Astro dev server on :4321
npm run build           # production build → dist/  (includes /resume.pdf)
npm run preview         # serve dist/ locally
```

## Resume — single source of truth

Everything in `src/data/resume.ts` flows into:

| Format | URL | Generated by |
|--------|-----|--------------|
| HTML | `/resume` | `src/pages/resume.astro` |
| PDF  | `/resume.pdf` | `scripts/build-resume-pdf.mjs` (Puppeteer renders `/resume-print`) |
| Markdown | `/resume.md` | `src/lib/resume-formats.ts` → `toMarkdown()` |
| Plain text | `/resume.txt` | `src/lib/resume-formats.ts` → `toPlainText()` |
| JSON Resume | `/resume.json` | `src/lib/resume-formats.ts` → `toJsonResume()` (schema v1.0.0) |

Each download tile on `/resume` also exposes "Open in Google Drive" and "Save to Dropbox" shortcuts.

## Content authoring

**Blog posts** live in [src/content/posts/](src/content/posts/) as MDX files. Frontmatter:

```yaml
---
title: "Post title"
date: 2026-04-20
summary: "One-sentence summary used in lists, RSS, and OG cards."
tags: [MDM, Apple]
cover: /apple-biz-2.png
coverAlt: "Alt text for the cover image"
coverCredit:           # Optional — for Unsplash credits etc.
  name: Photographer
  url: https://unsplash.com/...
draft: false           # Set true to hide from build
---

Markdown body. Inline HTML blocks (`<div class="callout">`, `<div class="pullquote">`, `<div class="sources">`, `<div class="shot-grid">`, `<div class="footer-line">`, `<figure>`) are styled via the `.prose-post` class in [src/styles/global.css](src/styles/global.css).
```

**Projects** live in [src/content/projects/](src/content/projects/). Project cards on `/projects` come from [src/data/projects.ts](src/data/projects.ts); only entries with a content collection file get a `/projects/:slug` detail page.

## Deployment (Cloudflare Pages)

```bash
npm run deploy
```

This runs `npm run build` (which builds the site AND generates `/resume.pdf`) and then `wrangler pages deploy dist --project-name=willworland`.

For a CI build environment, ensure Puppeteer can install Chromium (set no skip env vars). To deploy without the PDF (e.g. if Chromium can't be installed in CI), set `SKIP_RESUME_PDF=1`.

## Theme & design

Clean dev-portfolio aesthetic — sans-serif body, monospace accents for dates/tags, thin borders, no shadows. Light + dark mode driven by a `class="dark"` toggle on `<html>` (`localStorage` persisted, defaults to system preference).

- Accent color: `#2172d2` (Tailwind `accent-500`)
- Body font: Inter via Google Fonts
- Mono font: JetBrains Mono via Google Fonts
- Reading width: `max-w-3xl` (~720px) for prose, `max-w-5xl` for index pages
